# Contributing

This repository is a read-only mirror of the Strevokit Meeting SDK source. Changes are made upstream and synced here,
so pull requests are not accepted and are closed without review.

## Reporting a problem

Open a [GitHub Issue](https://github.com/AgiliaIT/strevokit-meeting-sdk/issues) and include:

- the `@strevokit/meeting-sdk` version;
- the browser and its version;
- the `MeetingError` code and the close reason, if any;
- the steps to reproduce, ideally as a minimal example.

Never include join tokens, API credentials, or other secrets in an issue.

## Security issues

Do not report security vulnerabilities in public issues. Open an issue asking for a private contact instead, without
any details of the vulnerability.
